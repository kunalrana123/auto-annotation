# Neuraa

**An AI-powered computer vision annotation engine that auto-labels image datasets — including the classes off-the-shelf models have never seen.**

Manual annotation is the bottleneck in every computer-vision project. Neuraa turns annotation from *creation* into *verification*: point it at a folder of images, describe the classes you want, and it labels them — automatically for common classes, and with a tiny human seed for novel ones.

Neuraa is in **Phase 1: Model Research**. The current focus is understanding how each foundation model behaves and proving the auto-labeling loop converges — not building the product yet.
